# Panora
Panorama carousel designer (React + Vite + Electron).
- `npm install`
- `npm run dev` live-reload desktop app · `npm run web` browser only
- `npm run dist` builds an installer for your OS into `dist/` / `release` (.exe, .dmg, .AppImage)
Photo search uses the free Openverse API (Creative Commons). Check each image's license before publishing.
Shortcuts: Ctrl/Cmd+Z undo, Shift+Z redo, D duplicate, Delete remove.
